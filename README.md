# AI漫剧创作 Skill v1.0

这是一个专为网文改漫剧打造的 AI 技能包，一键生成剧本、分镜、资产提示词和视频指令。

## 📥 如何下载
1. 点击本页面右侧边栏的 **Releases**。
2. 找到最新的版本，点击 **Source code (zip)** 下载压缩包。
3. 解压后即可看到所有技能文件。

## 🚀 如何使用
1. 仅支持对话的平台（如 ChatGPT、DeepSeek、Kimi）：打开 `SKILL.md`，全选复制里面的全部内容，粘贴到 AI 的对话框里。
2. 支持传文件的平台：直接把 `SKILL.md` 或整个文件夹当作附件上传。
3. 对 AI 说：`请严格遵循 SKILL.md 的“小说改剧本全流程 v1.0”执行，先向我索要小说原文片段。`

## 🛠️ 功能亮点
- 自带 10 大交付模块
- 内含 17 种镜头视觉逻辑库
- 专属负向词防崩坏模板
- 适配 Seedance 等下游视频模型

## 💡 局部修改指令
生成后如果想微调，可以直接对 AI 说：
`重做第3镜`、`换角色B音色`、`只改BGM`、`重新切片`。

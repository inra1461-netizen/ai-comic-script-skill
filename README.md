\# AI漫剧创作 Skill v1.0



\## 安装

1\. 解压后确认根目录包含 `SKILL.md`。

2\. 支持 Skills 上传的平台：直接上传整个 `ai-comic-script-skill` 文件夹，或压缩为 zip 后上传。

3\. 仅支持对话的平台：打开 `SKILL.md`，全选复制到系统提示/自定义指令；若平台只支持单文件，把 `references/` 与 `templates/` 内容追加到 `SKILL.md` 末尾一起粘贴。

4\. 新对话使用时发送：`请严格遵循 SKILL.md 的“小说改剧本全流程 v7.0”执行，先向我索要小说原文片段。`



\## 使用

先粘贴小说原文片段；再选择交互模式 A/B/C；按批次作答；确认配置后输出 10 个模块。

局部修改可发送：`重做第3镜`、`换角色B音色`、`只改BGM`、`重新切片`。
